# 体温单数据绘制模块说明文档

## 文件概述

文件路径：`src/cmpts/bts/draw-data/index.ts`
这是一个用于绘制体温单数据的核心模块，主要负责体温、脉搏、心率等生命体征数据的可视化展示。

## 核心功能

### 1. 数据绘制主函数 `drawData`

-   功能：绘制完整的体温单数据图表
-   主要绘制内容：
    -   体温数据（蓝色实心圆点）
    -   物理降温数据（红色空心圆点+虚线）
    -   心率数据（红色空心圆点）
    -   脉搏数据（红色实心圆点）
    -   疼痛评分（黑色实心圆点）
    -   日期和住院天数标注

## 数据结构设计

### 1. 时间维度

-   日期范围：7 天
-   每天 6 个时间段：
    -   上午：2 点、6 点、10 点
    -   下午：14 点、18 点、22 点

### 2. 数据接口

```typescript
interface VitalSigns {
    temperature: number; // 体温
    physicalCooling: number; // 物理降温
    pulse: number; // 脉搏
    heartRate: number; // 心率
    painScore: number; // 疼痛评分
}

interface TimeSlot {
    time: string; // 时间段（如："02:00"）
    data: VitalSigns;
}

interface DayData {
    date: string; // 日期（如："2024-01-02"）
    dayInHospital: number; // 住院天数
    timeSlots: TimeSlot[]; // 时间段数据
}

interface BtsData {
    days: DayData[]; // 7天的数据
}
```

## 技术特点

### 1. 坐标转换

-   使用统一的坐标转换逻辑
-   体温：`51 * unit - ((val - 34) / 0.2) * unit`
-   心率和脉搏：`51 * unit - ((val - 20) / 5) * unit`
-   疼痛评分：`11 * unit - (val / 2) * unit`

### 2. 动画效果

-   使用 zrender 的动画系统
-   折线绘制采用渐进式动画
-   物理降温连接线使用延迟动画

### 3. 样式设计

-   体温：蓝色实心圆点
-   物理降温：红色空心圆点
-   心率：红色空心圆点
-   脉搏：红色实心圆点
-   疼痛评分：黑色实心圆点

## 使用说明

### 配置参数

```typescript
interface BtsConf {
    unit: number; // 单位长度
}
```

### 调用方式

```typescript
drawData(canvas, {
    unit: 20, // 设置单位长度
});
```

## 注意事项

1. 数据值为 0 时表示该点不绘制
2. 所有坐标计算都基于配置的 unit 值
3. 动画效果可能会影响性能，建议在数据量较大时适当调整动画参数
