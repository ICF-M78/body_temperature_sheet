# 体温单辅助绘制工具说明文档

## 文件概述

文件路径：`src/cmpts/bts/draw-tools/index.ts`
这是一个提供基础绘制功能的工具模块，为体温单数据绘制提供底层支持。

## 核心功能

### 1. 基础绘制函数

#### `circle`

-   功能：绘制圆形
-   参数：
    -   中心点坐标
    -   半径
    -   样式配置（颜色、线宽等）

#### `line`

-   功能：绘制线段
-   参数：
    -   起点坐标
    -   终点坐标
    -   样式配置（颜色、线宽、虚线等）

#### `polygon`

-   功能：绘制多边形
-   参数：
    -   点坐标数组
    -   样式配置（填充色、边框等）

#### `text`

-   功能：绘制文本
-   参数：
    -   位置坐标
    -   文本内容
    -   样式配置（字体、颜色等）

## 使用说明

### 基础调用方式

```typescript
// 绘制圆形
circle(
    { x: 100, y: 100 }, // 中心点
    10, // 半径
    {
        // 样式
        stroke: 'blue',
        lineWidth: 1,
        fill: 'white',
    }
);

// 绘制线段
line(
    { x: 0, y: 0 }, // 起点
    { x: 100, y: 100 }, // 终点
    {
        // 样式
        stroke: 'red',
        lineWidth: 1.5,
        lineDash: [4, 2], // 虚线样式
    }
);
```

## 技术特点

### 1. 样式配置

-   支持自定义颜色
-   支持自定义线宽
-   支持虚线样式
-   支持填充样式

### 2. 动画支持

-   所有绘制函数都支持 zrender 的动画系统
-   可以通过 animate 方法添加动画效果

## 注意事项

1. 所有坐标都基于画布坐标系
2. 样式配置遵循 zrender 的配置规范
3. 动画效果需要考虑性能影响
