## ✨ 特性

- 🎨 美观的界面设计，提供最佳的视觉体验
- 📊 基于 ZRender 的体温数据可视化
- 🔒 数据本地持久化存储
- 📱 响应式设计，支持多端适配
- 🛠 基于 Vue3 组合式 API 开发
- 🔍 完整的 TypeScript 类型支持

## 🚀 快速开始

### 环境要求

- Node.js >= 18.0.0
- pnpm >= 8.0.0

### 安装

```bash
# 克隆项目
git clone https://github.com/yourusername/body_temperature_sheet.git

# 进入项目目录
cd body_temperature_sheet

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

### 构建

```bash
# 构建生产环境版本
pnpm build
```
